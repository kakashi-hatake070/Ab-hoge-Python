# NumPy Practice

Beginner-friendly NumPy practice covering arrays, attributes, initialization, indexing, slicing, stacking, splitting, arithmetic, trigonometry, transpose, and statistics.

## File

- numpy_practice.ipynb — corrected and organized practice notebook.

## Run it

1. Install NumPy: pip install numpy
2. Open the notebook in Jupyter Notebook, VS Code, or PyCharm.
3. Run the cells from top to bottom.

## Improvements included

- Fixed incorrect slicing comments and examples.
- Completed the 1D/3D array-attributes exercise.
- Added working split, sine, cosine, and tangent examples.
- Clarified transpose and empty-array usage.
